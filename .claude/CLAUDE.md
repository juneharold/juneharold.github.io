# juneharold.github.io

Personal portfolio for Juneha Hwang. Static site on GitHub Pages.

## Tech Stack
Astro + Tailwind CSS

## Design Direction
- Modern, clean, distinctive (not generic AI aesthetic)
- Dark mode support
- Creative typography (avoid Inter, Arial, Roboto)
- Subtle animations on scroll and hover
- Mobile-first

## Site Structure
- **Home**: hero, about, featured projects, blog preview, contact/socials
- **/blog**: Markdown posts via Astro content collections
- **/projects**: cards with description, tech stack tags, GitHub links

## Constraints
- Static site only, must deploy to GitHub Pages
- Small bundle size, fast load times
- All content version-controlled in this repo
